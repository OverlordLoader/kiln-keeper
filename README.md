# Kiln Keeper

A cozy idle game for iOS 17+ (portrait only), built with native SwiftUI + SpriteKit.

**The fantasy:** you tend a warm glass kiln. Each shelf slot fires a glass piece
over real time — tap a finished piece to collect it, sell pieces for coins, and
spend coins on three upgrade tracks: **+1 shelf slot**, **faster firing**, and
**rarer glass colors** (rarer = higher sell value). The kiln keeps working while
the app is closed: come back to a *"While you were away…"* summary (offline
progress is capped at 8 hours to stay fair).

Philosophy: the free game is genuinely playable and satisfying in the first
session — no hollow demo. Monetization is ads (opt-in rewarded + sparse
interstitials) and three one-time IAPs.

## Monetization setup

### In-app purchases (App Store Connect → Kiln Keeper → In-App Purchases)

Create exactly these products. IDs must match **character for character**.

| Product ID | Type | Price | Name |
|---|---|---|---|
| `app.kilnkeeper.game.removeads` | Non-consumable | $4.99 | Remove Ads |
| `app.kilnkeeper.game.skin.emberforge` | Non-consumable | $1.99 | Emberforge Kiln |
| `app.kilnkeeper.game.skin.tideglass` | Non-consumable | $1.99 | Tideglass Kiln |

- All purchases are StoreKit 2, verified on-device, finished via
  `Transaction.finish()`. `Transaction.updates` handles Ask-to-Buy/approvals
  on other devices; `AppStore.sync()` powers Restore Purchases; refunds revoke
  entitlements (a refunded skin is un-owned and unequipped).
- Skins visibly re-theme the kiln (bricks, mortar, fire, embers).

### AdMob checklist (Henry)

1. AdMob account → **Apps** → Add app → iOS → **Kiln Keeper**.
2. **Ad units** → create one **Rewarded** and one **Interstitial** unit.
3. Paste the two unit IDs into `KilnKeeper/Game/AdsManager.swift` where marked
   `// TODO(Henry): replace with real AdMob IDs` (release section only —
   debug builds always use Google's official test IDs).
4. Replace `GADApplicationIdentifier` in `KilnKeeper/Info.plist` with your real
   AdMob App ID (currently Google's official test ID).
5. Banking/tax: complete **Payments** → bank account + tax forms in AdMob
   before release, or earnings can't be paid out.
6. App-ads.txt: publish your `app-ads.txt` if you run a developer website.

Ad behavior: rewarded placements are **2x firing speed for 10 minutes** and
**instant-finish one shelf** (opt-in buttons on the main screen, hidden for
Remove-Ads owners). Interstitials show at most once per ~5 minutes of play,
only on screen transitions (sheet open/dismiss), never mid-tap/collect, never
in the first session. Ads degrade gracefully offline — gameplay never blocks.

### Privacy labels

`PrivacyInfo.xcprivacy` declares **Device ID** for **Third-Party Advertising**,
linked=false, tracking=false (no IDFA, no AppTrackingTransparency). No accounts or separate analytics SDK are implemented. This does not establish that the advertising SDK collects no other data.

## Balance (first-session friendly)

- Start: 3 shelves, 50 coins, 60s base fire time.
- ~3–4 minutes of firing buys the 4th shelf (100¢); speed and rarer-glass
  tracks stay within reach the whole first session.
- Rarity sell values: Common 10¢ → Uncommon 25¢ → Rare 60¢ → Epic 140¢ →
  Legendary 320¢. Higher tiers fire less often (weighted random).
- Offline: the kiln keeps firing while the app is closed, capped at 8 hours.

## Release

The signed-release pipeline mirrors Henry's other apps. The workflow file is
**not** in this repo (GitHub restricts `.github/workflows` to the repo owner):
it's at `~/workspace/your_files/kilnkeeper-apple-release.yml` — upload it via
the GitHub web UI when ready, then dispatch it manually from the Actions tab.

Per-release secrets live in the `app-store-release-kilnkeeper` environment:
`APPLE_DISTRIBUTION_P12_BASE64`, `APPLE_DISTRIBUTION_P12_PASSWORD`,
`APPLE_PROFILE_BASE64` (App Store profile for `app.kilnkeeper.game`),
`APP_STORE_CONNECT_KEY_BASE64`.

```bash
python3 scripts/apple-release-check.py   # safety checks, no Apple signing
```


## Current launch-review status (September 30, 2026)
